# Privacy Policy — Neptune Bot

*Last updated: June 2026*

## 1. Introduction

This Privacy Policy describes what data Neptune Bot collects, how it is used, and how it is stored. By using Neptune Bot, you agree to the collection and use of your data as described in this policy.

## 2. Data Collected

Neptune Bot collects and stores the following data when you interact with it:

| Data | Purpose |
|------|---------|
| Discord User ID | Uniquely identifies you in the database |
| Display name | Used for leaderboards and rank display |
| Message count | Tracks activity for the leveling system |
| XP and Level | Powers the leveling and role reward system |
| XP requirement | Tracks progress to next level |
| In-game money | Powers the economy system |

This data is collected automatically when you send a message in a server where Neptune Bot is active.

## 3. How Data is Used

Your data is used solely to power the bot's features:

- **Leveling system** — XP, level, and message count are used to track your progress and assign level roles
- **Economy system** — In-game money is used for commands such as `!send`, `!rob`, `!roll`, and betting
- **Leaderboards and rank cards** — Your level, XP, and display name are shown in server leaderboards and rank embeds

Your data is never sold, shared with third parties, or used for advertising.

## 4. Data Storage

All data is stored locally in a SQLite database (`message_count.db`) on a private server. The data is not shared with any external services.

## 5. Data Retention

Your data is retained for as long as Neptune Bot is active. If you wish to have your data removed, please contact the bot owner via Discord.

## 6. Third Party Services

Neptune Bot uses the following third party services:

- **Discord API** — Required to operate as a Discord bot. Discord's own [Privacy Policy](https://discord.com/privacy) applies to all data handled by Discord.
- **Tenor** — Used to display GIFs. No user data is sent to Tenor.

## 7. Children's Privacy

Neptune Bot does not knowingly collect data from users under the age of 13. Discord's own Terms of Service require users to be at least 13 years old.

## 8. Changes to This Policy

This Privacy Policy may be updated at any time. Continued use of the bot after changes constitutes acceptance of the updated policy.

## 9. Contact

If you have any questions about this Privacy Policy or wish to request data deletion, please reach out via Discord.
